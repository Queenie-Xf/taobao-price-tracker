# 使用手册 | 淘宝 / 天猫价格追踪

本手册对应公开 GitHub 版本。项目需要用户本机的 Windows、Chrome、Node.js 和 Python；不会自动部署到 GitHub Actions，也不能脱离登录态在云端抓取。

## 安装

1. 下载或 Clone 仓库，进入根目录。
2. 安装 Node.js 22+、Python 3.9+ 和 Chrome。
3. 安装 Python 包：`python -m pip install -r requirements.txt`。
4. 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\ensure_chrome.ps1`。
5. 此命令会开启**独立浏览器配置**，首次使用需在这个新 Chrome 窗口手动登录淘宝。

请勿将 Chrome 的远程调试端口绑定到公网，也不要在专用浏览器中登录其他敏感账户。脚本不会强制关闭已有的普通 Chrome。

## 输入数据

在 Excel 第一张表的第 1 行设置表头，第 2 行起填充数据：

| A 分组 | B 目标列 | C 品牌 | D 商品直链 |
|---|---|---|---|
| 鱼油 | C | 品牌 A | `https://detail.tmall.com/item.htm?id=...` |
| 鱼油 | D | 品牌 B | `https://item.taobao.com/item.htm?id=...` |

生成配置：

```powershell
python .\scripts\init_tasks.py "C:\path\products.xlsx" tasks.json
```

或者复制 `examples/tasks.example.json` 为 `tasks.json` 并替换示例链接（示例 ID 不真实）。广告跳转地址解析不成功的会记录在 `pending.json`，需要手动获取有效商品页链接。

## 采集、报告

```powershell
$env:TASKS="tasks.json"
$env:PORT="9224"
$env:IMG_DIR="competitor_images"
$env:RESUME="0"    # 新的一天首次运行
node .\scripts\fetch_prices.mjs
python .\scripts\build_report.py .\competitor_images\results.json .\price_report_20261123.xlsx --tasks .\tasks.json --period 2026-11-23
```

请把示例日期改成当天日期。当天补采失败列可以将 `RESUME` 改成 `1`。**换日后请重新设为 `0`**；现有续跑逻辑不按日期自动清除成功记录。

## Excel 结构

一列一个商品。B2 为采集日期标签；第 3–7 行分别为品牌、网址链接、商品名称、优惠后价、优惠前价。`price_history.csv` 为历史优惠后价，每个日期对应一行。若该商品无合法优惠后价，留空而不是填零。

## 价格口径

- 优惠后：页面文本中的「优惠后、加补后、补贴后、券后、到手」等价格，兼容其它价格候选。
- 优惠前：页面中的「优惠前、预售价、日常价、原价」，再回退至划线价。
- 默认价格有效区间为 **20–5000 元**，由原鱼油样本设定，其他品类应调整 `scripts/build_report.py` 中的阈值。
- 多规格商品、领券资格、地区或账号可能显示不同价格；报告只是当前页面快照，不代表结算价。

## 异常排查

| 现象 | 建议 |
|---|---|
| `CDP_FAILED` | 检查独立 Chrome 是否能启动，本机端口 9224 是否被其他程序占用 |
| 页面跳转登录 | 在**独立 Chrome 窗口**中手工重新登录 |
| `blocked` / 验证码 | 停止访问，按平台提示人工处理，不尝试破解 |
| 优惠前价有值但优惠后为空 | 可能是促销价未显示或页面不完整；保持空值，稍后人工核查 |
| 部分商品不在结果中 | 检查 `tasks.json`、链接有效性、`pending.json` 和运行日志 |
| 次日价格和昨日完全一样 | 检查新一天首次运行前是否设置 `RESUME=0` |

## 自动调度

如需每日自动化，可在用户自己的 Windows Task Scheduler 中按顺序执行启动浏览器、采集和报告步骤。首次登陆、验证码、浏览器关闭等仍可能需要人工处理。仓库本身不会自行注册系统定时任务。

## 隐私提醒

运行目录中可能存在真实竞品名称、商品链接、价格历史和浏览器会话。公开分享代码时，只上传项目源代码和模拟示例数据；避免提交账号相关数据。
